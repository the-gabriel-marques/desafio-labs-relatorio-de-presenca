# Desafio Labs - Relatório de Presença 📊

Este projeto foi desenvolvido como parte dos desafios da **Labs Talents**. O objetivo é gerenciar e visualizar a presença de mentorandos em diferentes encontros, fornecendo métricas claras de engajamento.

## 🚀 O que o projeto faz?
O sistema funciona como um gerador de relatórios automatizado que:
* **Busca por Encontro:** Localiza dados específicos de um workshop ou palestra pelo nome.
* **Cálculo de Métricas:** Exibe o total de inscritos, quantidade de presentes, número de faltas e a taxa percentual de presença.
* **Classificação:** Indica visualmente se a adesão foi "Ótima", "Regular" ou "Baixa".
* **Ranking:** Apresenta um ranking geral de todos os encontros realizados.
